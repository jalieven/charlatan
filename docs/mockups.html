Charlatan · Design review

Charlatan Mockups

Thirty-three frames covering all ten screens, S1–S10, in flow order — including the reveal's four states, the second-tie warning, the three-act result, the round menu that hangs off the clue screen, and the forgot-your-word re-check with its optional per-player PIN. In-app copy is Dutch — the default locale per §6.4. One running scenario throughout: six players, koffie/thee, Tom is the Charlatan. Annotations under each frame say what to validate.

Setup — a PIN button on every row

No PIN field, no OS keyboard: adding a player is name + +, exactly as before. Every player row carries a quiet PIN pill instead — tap it to set a code on the keypad sheet (next frame); a filled PIN ✓ pill marks who has one. Tapping a filled pill re-opens the sheet to change the code — current code first. The PIN exists for one purpose: unlocking that player's word re-check during the round (S4c). Same pills when someone joins mid-session from the scoreboard.

Setting a PIN — step 1, choose

Round 56 px keys on a bottom sheet: the OS keyboard never opens and the code is only ever anonymous dots — never text in a field. The code is at least four digits but has no fixed length: four hollow placeholders fill first, every extra digit appends a dot (five here). ✓ stays disabled until four digits are in; tapping it moves to step 2. Cancel (or tapping the scrim) closes the sheet without saving.

Launch — resume or new game

An unfinished round survives indefinitely (§4). Choosing "nieuw spel" is the explicit end of the old round; resuming re-enters via the handoff interstitial, never on private data (§6.3).

2b · Word — the long tail

The deck's longest entries run to 25–28 characters. They keep the hero's single line: the type scales down from the 54 px cap until the word fits — never wrapping, never breaking mid-word (a break would hand the reader a false compound). The word stays the largest thing on screen, and the deck's worst case still lands above the readability floor. The one-line definition underneath keeps its own size, so a long word never reads as a less important one.

4 · Role card — held, Charlatan

The card grows upward from the held role button, so the dashed Whisper target sits directly above the thumb: hold → one thumb-width slide up → release-to-commit (§3.3). Releasing anywhere else closes the card. The civilian card shows a same-position target that just closes; the target is absent once the round's Whisper is burned — the accepted tell (§3.6).

S4 · Clue entry & Ledger

Type it, then say it aloud

The active player types their one-word clue, confirms, and says it aloud (§3.5). The Ledger — every clue this round, grouped by cycle — is always visible below, and it is a neutral record: suspicion markers (◆) exist only in the post-round replay, never live. Warnings are private and never block. No timer anywhere.

2 · Extra cycle after the second tie

The tie-stakes banner is a hard requirement: it appears the moment the second consecutive tie happens and persists through this cycle and the next ballot (§3.7). Bram, voted out earlier, is struck from the order — which stays otherwise stable within the round (§3.4). Cycle counters grow past the base 2 with every tie/ejection loop.

S4b · Round menu

The two exits from a running round

A settings affordance sits top-right of the clue screen — the only screen where the phone is public, so the only screen that can carry it. It opens a two-entry popover: the session standings, and an escape hatch for a round that has gone wrong (a misread word, a player who saw the wrong screen, someone who has to leave). Both entries carry a line glyph in the same 1.5 px monochrome voice as the rest of the app: a ranking bar chart for the score, the universal skip-track mark for abandoning the round.

3 · Score sheet

"Score" raises a read-only sheet over the round — it is not the S9 scoreboard: no roster editing, no next-round button, no way out of the round. Cumulative session scores and the round history only, so the table can settle an argument without the round state being touched. Closing returns to the exact clue turn underneath.

S4c · Woord vergeten

The word, retrievable — never exposed

Forgetting your word mid-round used to be unrecoverable. Now every player pill on the clue screen is a button: tap your own name and a re-check opens, gated the way the reveal is — by your PIN if you set one at setup, by the handoff slider if you didn't — and the word itself sits behind the same swipe-up-and-hold cover. Nothing else moves: the turn, the speaking order and the peek economics are untouched, there is no role card here, and a Whispered player sees the same two-word display as in the reveal — a re-check can never betray the plant.

3 · The word — same cover, same physics

Past the gate, the word sits behind the identical swipe-up-and-hold cover: visible only while held, instant snap shut on release. No role button — peeking economics stay what they were in the reveal — and no slide-to-continue: the only way out is back to the hints. A Whispered player gets the two-word display here too, so re-checking reveals nothing new.

S5 · S6 · S7 — Vote, verdict & the steal

Private ballots, open verdicts

Ballots are individual and private via the handoff (§3.7): no self-votes, no abstentions, eliminated players excluded. The verdict announces roles openly; a caught Charlatan immediately gets one typed guess at the real word (§3.8).

S7 · The steal

Typed, one attempt, case-insensitive with singular/plural tolerance (§3.8). The guess is shown at the result so the table can judge a near-miss. A correct guess wins the round for all Charlatans.

S8 · Result

Three acts, narrated by the phone-holder

One act per screen, advanced by tap, three-dot strip, back-swipe allowed — everything here is public. The word pair is part of the first act, not a drill-in behind a button: the round's secret is the first thing the table wants back. Scenario: round 4 — Bram (a burger) was voted out mid-round, then Tom was caught on the fourth vote; steal missed, burgers win. Eliminated Bram still scores the team win (§3.9), but had no vote in the ejecting ballot.

Act 1 · Long pair — the row breaks, the words don't

Side by side each card owns barely half the width, so a long pair broke mid-word into nonsense. Each card now asks for the width its word needs at the readability floor; when both can't have it the row wraps and the pair stacks full-width. Same two cards, same order (real first) — only the room changes. Both words share one size, so neither typography nor position hints at which is which.

Act 3 · The damage

A score matrix (§3.9): players down the left, the round's subscores across the top, totals on the right behind a hairline — tabular numerals, heaviest weight on the total, em-dashes for nothing-earned. Columns adapt to the outcome: a Charlatan-win round shows overleefd / blind ×2 / steal instead. One footnote line carries the human context. Continue lands on the scoreboard (S9).

S10 · Sessie-overzicht

The session's parting shot

"Einde sessie" no longer drops straight back to setup: it lands here first — final standings, one fun fact per player mined from the round history, and a set of session awards. Everything is computable from what RoundSummary already records (peeks, ballots, deltas, whispers, steals); skipped rounds are excluded from every ratio. Only "SLUIT AF" actually resets to setup. Scenario continues: six players, seven rounds, one skipped. One scrolling screen, shown here as three frames.
